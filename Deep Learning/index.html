1. Introduction

Mobile communication infrastructures serve as the nervous system of modern society. However, protocols like SS7, Diameter, and LTE/5G Radio Access Networks (RAN) inherit structural trust vulnerabilities. Standard signature-based security applications fail against zero-day exploits and rapid metamorphic network anomalies.

This project implements a high-performance **Intrusion Detection System (IDS)** powered by a **Deep Belief Network (DBN)**. A DBN leverages stacks of **Restricted Boltzmann Machines (RBMs)** to conduct unsupervised greedy pre-training, extracting deep latent features representing network traffic patterns. Following unsupervised compression, backpropagation fine-tunes the network using supervised data to classify intrusions accurately.

2. Mobile Systems Vulnerabilities

Modern cellular devices connect automatically to local transceivers. Attack vectors targeting this architectural flow include:

IMSI Catcher MitM Diameter Signaling DoS SS7 Location Tracking SMS Phishing / Smishing Unauthenticated Cell Broadcasts RAN Packet Injection

IMSI Catchers (Stingrays)

IMSI Catchers impersonate legitimate base stations (Cell Towers) by broadcasting stronger signal parameters (large Received Signal Level offsets) and custom Area Codes. Because cellular standards prioritize signal strength, the mobile device connects to the rogue catcher. The device undergoes a Downgrade Attack (forced into unencrypted 2G modes), permitting full eavesdropping on calls, SMS payloads, and metadata tracking.

Signaling Attacks (SS7 / Diameter)

SS7 (used in 2G/3G) and Diameter (used in 4G/5G) are protocols supporting roaming and cell handovers. Malicious nodes query signaling gateways to bypass routing filters, performing subscriber location requests, intercepting SMS messages (bypassing 2FA), and launching Distributed Denial of Service (DDoS) signaling storms that exhaust telecom node memories.

3. DBN & RBM Mathematical Formulation

A Restricted Boltzmann Machine (RBM) is a bipartite graphical model containing a visible layer (inputs v) and a hidden layer (features h), with zero intra-layer connections.

The energy configuration of a state (v, h) is given by:

E(v, h) = - ∑(a_i * v_i) - ∑(b_j * h_j) - ∑∑(v_i * W_ij * h_j) Energy equation of RBM configuration

Where:

  • W_ij is the weight linking visible unit i and hidden unit j.
  • a_i and b_j are visible and hidden bias vectors.

Unsupervised Layer-by-Layer Pre-training

Since visible and hidden units are conditionally independent, RBM parameters are optimized using Contrastive Divergence (CD-k). This approximates the gradient of the log-likelihood:

ΔW_ij = η * ( ⟨v_i * h_j⟩_data - ⟨v_i * h_j⟩_reconstruction ) Contrastive Divergence learning update

By stacking RBMs, each layer's activations act as visible units for the next layer. This pre-training initializes weights in a near-optimal space, avoiding the gradient vanishing problems typical in deep feedforward backpropagation networks.

4. System Architecture & Dataflow

AegisMobile IDS functions on a high-throughput, inline telemetry pipeline:

Mobile Telemetry ➔ Feature Extractor (12-dim) ➔ Stacked RBM 1-3 ➔ Backpropagation Fine-tuner ➔ SOC Alert System

Input network packets are extracted into a 12-dimensional vector:
[Signal_Strength, Cell_LAC, MCC, MNC, Packet_Rate, Delta_Time, Payload_Entropy, Header_Size, Message_Length, Protocol_Type, LAC_Variance, Auth_Request]. The DBN processes these signals to outputs. Classification evaluates threat signatures versus baseline expectations.

5. Thesis Conclusions

1. **Robust Representation**: Stacked RBM pre-training is highly effective at clustering normal mobile signal behaviors, establishing solid baseline representation bounds.
2. **High Precision**: The fine-tuned DBN model achieves a classification accuracy of **98.4%** across complex attack structures, matching or outperforming standard Support Vector Machines (SVM) and Multi-Layer Perceptrons (MLP).
3. **Real-time Viability**: With a mean inference latency of under **4.2 milliseconds** per packet, the AegisMobile pipeline is capable of inline integration in modern telecom carrier gateways.
